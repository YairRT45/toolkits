# Sistema de gestión de Toolkits y revisiones del departamento de envasado

### Comandos


> `docker compose up -d --build`
>
> `docker compose down`
>
>`docker compose up -d`
>
>`docker compose exec toolkits bash`
>
>`python manage.py makemigrations`
>
>`python manage.py migrate`
>
>`python manage.py createsuperuser`
>
>`python manage.py runserver 0:8000`
